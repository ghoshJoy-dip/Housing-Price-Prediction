
# Housing Price Prediction

A machine learning regression project focused on
exploring housing data and predicting property prices.

## Project Overview

This project aims to analyse housing data, identify
the factors influencing property prices, and develop
regression models to predict housing prices.

## Objectives

- Perform exploratory data analysis (EDA).
- Clean and preprocess the dataset.
- Perform feature engineering.
- Develop regression models.
- Evaluate and compare model performance.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
